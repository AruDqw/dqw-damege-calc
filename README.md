# ⚔️💚 DQW 計算ツール

ドラゴンクエストウォークの**物理ダメージ計算**と**回復量計算**をまとめたブラウザ完結型のツールです。  
HTMLファイル単体で動作し、サーバー不要・インストール不要です。

---

## 使い方

`index.html` をブラウザで開くだけで使用できます。  
上部のタブで **⚔️ ダメージ** / **💚 回復** を切り替えて使用します。  
値を入力するたびに自動で再計算されます。最後に開いていたタブはブラウザに記憶されます。

---

# ⚔️ 物理ダメージ計算機

## 入力項目

### 攻撃力・基礎値

| 項目 | 説明 |
|------|------|
| 攻撃力 | キャラクターの攻撃力 |
| バイシオン（段数） | 0〜3段。攻撃力 × 段数 × 20% を加算 |
| レベルアップ（段数） | 0〜20段。`floor(1.04^段数 × 100) / 100` で倍率を求め、`floor(攻撃力 × 倍率) − 攻撃力` を加算 |
| 剣魔合一（加算値） | LvUPと同じ倍率で `floor(入力値 × 倍率)` を計算し加算 |
| 敵の守備力 | 基礎値計算で使用 |
| 敵の守備力変化（段数） | −3〜+3。レベルダウン前の守備力 × ±20% × 段数（切り捨て） |
| 敵のレベルダウン（段数） | 0〜10段。`ceil(0.96^段数 × 100) / 100` で係数を算出 |
| 直撃 | あり／なし。ありの場合は最終守備力が 0 になる |

**基礎値** = `floor( (攻撃力 + バイシオン + LvUP + 剣魔合一) / 2 − 最終守備力 / 4 )`

**乱数幅** = `floor( 基礎値 / 16 )`  
**下限基礎値** = `floor( 基礎値 − 乱数幅 ) − 1`  
**上限基礎値** = `floor( 基礎値 + 乱数幅 ) + 1`

---

### スキル・テンション・各種倍率

物理ダメージ計算機の詳細な入力項目・計算式については以下を参照してください。

## 計算式（全体フロー）

```
① LvUP倍率   = floor( 1.04^段数 × 100 ) / 100
   LvUP加算値 = floor( 攻撃力 × LvUP倍率 ) − 攻撃力
   剣魔合一   = floor( 入力値 × LvUP倍率 )

② 敵LvDown係数 = ceil( 0.96^段数 × 100 ) / 100
   最終守備力  = floor( 守備力 × LvDown係数 ) + 守備力変化（直撃時は 0）

③ 基礎値     = floor( (攻撃力 + バイシオン + LvUP + 剣魔合一) / 2 − 最終守備力 / 4 )

④ 乱数幅     = floor( 基礎値 / 16 )
   下限基礎値 = floor( 基礎値 − 乱数幅 ) − 1
   上限基礎値 = floor( 基礎値 + 乱数幅 ) + 1

⑤ テンション補正（T = 1 + 味方テンション% / 100）
   斬体% / 属性% / 系統% / 名称% / 会心ダメアップ% → floor( 入力値 × T )
   斬体耐性% / 属性耐性% → floor( 入力値 × 敵T補正 / 100 )

⑥ 各倍率（%→倍率変換後は小数第3位切り捨て）
   斬体合計         = floor( (100 + 斬体% + スキルUP + 斬体UP + おうえん) / 100 × 1000 ) / 1000
   属性合計         = floor( (100 + 属性% + FC×30 + FB) / 100 × 1000 ) / 1000
   系統合計         = floor( (100 + 系統%) / 100 × 1000 ) / 1000
   名称合計         = floor( (100 + 名称%) / 100 × 1000 ) / 1000
   因果合計         = 1 + (段数×20 + 極みあり×30) / 100
   FB＋属性耐性変化 = 1 + (FB段数×30 − 属性耐性変化段数×20) / 100
   会心合計         = (会心種別% + 会心ダメアップ%) / 100
   斬体耐性変化合計 = (100 + 斬体耐性変化 + 衰弱 + 凍結 + 戦意喪失) / 100

⑦【第1段階】= floor( 基礎値 × スキル倍率 × 斬体合計 × 属性合計
                    × 系統合計 × 名称合計 × 因果合計 × (FB＋属性耐性変化)
                    × 斬体耐性 × 属性耐性 × 閃き × 会心合計 × 斬体耐性変化合計 )

⑧【第2段階】最終ダメージ = floor( ⑦ × スキル倍率補正 × きあいため )

※ 最小は下限基礎値・会心下限%、最大は上限基礎値・会心上限%で⑦⑧を同様に計算
```

---

## 計算結果の保存

入力値はブラウザの localStorage に自動保存されます。  
画面下部の履歴エリアに最大3件まで保存・呼出が可能です。

# 💚 回復量計算機

## 入力項目

### 武器

| 項目 | 説明 |
|------|------|
| 武器 | 使用する回復武器を選択。武器ごとに基礎回復量の計算式が異なる |

武器には **とくぎ** / **呪文** の属性があり、装着する心の属性と一致しない場合、心の「呪文とくぎHP回復効果%」が無効になります。

現在対応している武器：

| 武器名 | 属性 | 回復魔力上限 |
|--------|------|-------------|
| 道示す光 | とくぎ | 1900 |
| 女神の奇跡 | 呪文 | 2100 |
| いやしの占術 | とくぎ | 1350 |

### ステータス

各ステータスは **未装着**（心なし）と **装着後**（心込み）の両方から入力できます。片方を入力すると自動でもう片方に反映されます。

| 項目 | 説明 |
|------|------|
| 回復魔力 | 武器の基礎回復量に影響。武器ごとの上限あり |
| スキルHP回復効果（%） | 基礎回復量への乗算倍率 |
| とくぎ/呪文HP回復効果（%） | 基礎回復量への乗算倍率。武器と心の属性が不一致の場合、心による加算分は無効 |

### レベルアップ・テンション

| 項目 | 説明 |
|------|------|
| レベルアップ（段数） | 回復魔力に `floor(1.04^段数 × 100) / 100` を乗算（上限あり） |
| テンション | 0 / 5 / 20 / 50 / 100。スキルHP回復%・とくぎ呪文HP回復%に T 倍率を乗算後切り捨て |

---

## 計算式

```
① 実効回復魔力 = min( floor( (回復魔力 + 心の回復魔力合計) × レベル倍率 ), 武器上限 )

② 基礎回復量  = 武器固有の切片 + 傾き × 実効回復魔力
   （2点の実測値から線形補間で算出）

③ T = 1 + テンション% / 100
   有効スキル%  = floor( スキルHP回復% × T )
   有効とくぎ%  = floor( とくぎ/呪文HP回復% × T )

④ 回復量 = floor( 基礎回復量 × (1 + 有効スキル% / 100) × (1 + 有効とくぎ% / 100) )
```

---

## こころ（自由欄）

4スロットに心を装着できます。各スロットで独立して選択可能で、ステータスはすべて加算されます。

### 心の属性

- **属性なし**（どちらの武器でも全ステータス有効）
- **とくぎ専用**：とくぎ武器以外では「呪文とくぎHP回復効果%」が無効
- **呪文専用**：呪文武器以外では「呪文とくぎHP回復効果%」が無効

属性不一致の心を装着すると、スロット下に警告が表示されます。

### コスト管理

各心にはコストがあり、キャラクターレベル（80〜90）と装着中の心の組み合わせで最大コストが決まります。

**最大コスト** = レベル基礎値 + 装着中の心のコストボーナス合計

| レベル | 基礎値 |
|--------|--------|
| 90 | 700 |
| 89 | 694 |
| 88 | 689 |
| 87 | 683 |
| 86 | 678 |
| 85 | 673 |
| 84 | 667 |
| 83 | 661 |
| 82 | 655 |
| 81 | 649 |
| 80 | 643 |

合計コストが上限を超えると赤字で警告が表示されます。

### ⚡ オートボタン

現在の武器・キャラレベル・コスト上限・各ステータスを考慮して、回復量が最大になる心の組み合わせを自動で選択します。全C(n,4)の組み合わせを探索します。
