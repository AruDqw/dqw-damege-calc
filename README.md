# ⚔️🔮💚 DQW 計算ツール

ドラゴンクエストウォークの **物理ダメージ計算**・**呪文ダメージ計算**・**回復量計算** をまとめた、ブラウザ完結型のツールです。 [👉 ツールを開く](https://arudqw.github.io/dqw-damege-calc/)  
HTMLファイル単体で動作し、サーバー不要・インストール不要です。

> ※ 計算結果は目安です。ゲーム内の表示と異なる場合があります。

---

## 使い方

上のリンクを開くだけで使用できます（`index.html` をブラウザで開いても動作します）。  
上部のタブで **⚔️ ダメージ** / **🔮 呪文** / **💚 回復** を切り替えます。

- 値を入力するたびに自動で再計算されます
- 画面下部に最終結果が常に表示されます
- 最後に開いていたタブと、⚔️ ダメージ・🔮 呪文の入力値は、ブラウザ（localStorage）に自動保存されます（💚 回復の入力値は保存されません）
- 保存先はブラウザ×端末ごとに独立しています（別のブラウザ・端末には引き継がれません）

# ⚔️ 物理ダメージ計算機

## 職業選択

| 職業 | 専用項目（選択した職業のみ表示） |
|------|------------------------------|
| 魔剣士 | 剣魔合一／フォースチャージ／フォースブラスト／因果の極み／因果 |
| 魔人 | 痛恨の一撃／根絶やし／根絶やしマインド／二刀流（第3段階） |
| ゴドハン | ゴッドレイジ |
| ALL | すべて表示 |

選んだ職業以外の専用項目は非表示になり、計算では 0（二刀流のみ 100%）として扱われます。  
最終結果の帯の色も職業で変わります（魔剣士＝赤／魔人＝青／ゴドハン＝緑／ALL＝茶）。初期状態は魔剣士です。

---

## 入力項目

### 攻撃力・基礎値

| 項目 | 説明 |
|------|------|
| 攻撃力 | キャラクターの攻撃力 |
| バイシオン（段数） | 0〜3段。攻撃力 × 段数 × 20% を加算 |
| レベルアップ（段数） | 0〜20段。`floor(1.04^段数 × 100) / 100` で倍率を求め、`floor(攻撃力 × 倍率) − 攻撃力` を加算 |
| 剣魔合一（加算値） | 魔剣士専用。LvUPと同じ倍率で `floor(入力値 × 倍率)` を計算し加算 |
| 敵の守備力 | 基礎値計算で使用 |
| 敵の守備力変化（段数） | −3〜+3。レベルダウン前の守備力 × 20% × 段数（切り捨て） |
| 敵のレベルダウン（段数） | 0〜10段。`ceil(0.96^段数 × 100) / 100` で係数を算出（1段階=96%、2段階=93%、10段階=67%） |
| 直撃 | あり／なし。ありの場合は最終守備力が 0 になる |

**最終守備力** = `floor(守備力 × レベルダウン係数) + 守備力変化`（直撃時は 0）  
**基礎値** = `floor( (攻撃力 + バイシオン + LvUP + 剣魔合一) / 2 − 最終守備力 / 4 )`  
**乱数幅** = `floor( 基礎値 / 16 )`　→　**下限基礎値** = `floor(基礎値 − 乱数幅) − 1`、**上限基礎値** = `floor(基礎値 + 乱数幅) + 1`

### スキル

| 項目 | 説明 |
|------|------|
| スキル倍率（%） | 使用スキルの倍率（例：覇王斬 = 900）。**第1段階**で乗算 |
| スキル倍率補正（%） | 心珠などによるスキル倍率アップ（例：30×2段 = 60）。**第2段階**で乗算 |

### テンション

味方テンションを選択します（T = テンション倍率）。

| 選択 | 0 | 5 | 20 | 50 | 100 |
|------|---|---|----|----|-----|
| T | ×1.0 | ×1.1 | ×1.2 | ×1.3 | ×1.5 |

斬体倍率%・属性倍率%・系統倍率%・名称倍率%・会心ダメアップ% は、`floor(入力値 × T)` と **整数切り捨て** してから使われます。

### ゾーン編成

自分と仲間1〜3の職業を選びます。ゾーンに入っている職業の特性が、斬体・属性・会心の各ダメージに自動で反映されます。

| 職業 | 自分がゾーン | 仲間がゾーン |
|------|-------------|-------------|
| ゴッドハンド／ドラゴン／時渡りの剣士 | 斬体 +150% | 斬体 +45% |
| スーパースター | （自分では選択不可） | 斬体 +45% |
| 魔剣士／天地雷鳴士 | 属性 +150% | 属性 +45% |
| 魔人／大魔導士 | 会心 +230% | 会心 +69% |
| その他 | T×1.5 のみ | 効果なし |

- **自分がゾーンに入る**と、テンション100扱い（T = ×1.5 固定）＋職業特性が適用されます
- 仲間は職業特性のみ適用されます
- **同じ職業は何人いても1回しか加算されません**（自分＝魔人・仲間＝魔人 → 会心 +230%）
- 違う職業なら加算されます（自分＝魔人・仲間＝大魔導士 → 会心 +299%）
- 属性ゾーンは「フォース」にチェックを入れているとき `÷2（切り捨て）` されます

### 斬体ダメージ

| 項目 | 説明 |
|------|------|
| 斬体倍率（%） | テンション補正あり → `floor(入力値 × T)` |
| その他斬体倍率補正（%） | フウラ、心珠（分身の術）など |
| スキルダメージアップ（段数） | ラーミアなど。1段階 +20%（最大3段階） |
| 斬体ダメージアップ（段数） | 円月輪など。1段階 +20%（最大3段階） |
| おうえん | あり +80% ／ なし |
| ゾーン | ゾーン編成から自動反映 |
| ゴッドレイジ（%） | ゴドハン専用。40 + 75(心道) + Lv×2.5（Lv90で最大340） |
| 会心必中 | あり +50% ／ なし |

**斬体合計** = `floor( (100 + 斬体% + その他 + スキルUP + 斬体UP + おうえん + ゾーン + ゴッドレイジ + 会心必中) / 100 × 1000 ) / 1000`（小数第3位切り捨て）

### 属性ダメージ

| 項目 | 説明 |
|------|------|
| 属性倍率（%） | 「フォース」にチェックを入れると `÷2（切り捨て）` してから `floor(× T)` |
| フォースチャージ（段数） | 魔剣士専用。0〜6段、1段につき +30% |
| フォースブラスト | 魔剣士専用。あり +125% ／ なし（テンション補正なし） |
| ゾーン | ゾーン編成から自動反映（フォース時は ÷2） |

**属性合計** = `floor( (100 + 属性% + FC×30 + FB + ゾーン) / 100 × 1000 ) / 1000`

### 系統・名称ダメージ

| 項目 | 説明 |
|------|------|
| 根絶やし | 魔人専用。あり +300% ／ なし |
| 根絶やしマインド | 魔人専用。+0 / +60 / +120 / +180% |
| 系統倍率（%） | `floor( 入力値 × (T + 根絶やし合計% / 100) )` |
| 名称倍率（%） | `floor( 入力値 × T )` |

**系統合計** = `floor( (系統% + 100) / 100 × 1000 ) / 1000`　／　**名称合計** も同様。

### 敵テンション・耐性補正

| 項目 | 説明 |
|------|------|
| 敵テンション | 100→+50% / 50→+30% / 20→+20% / 5→+10% / 0→0% / −5→−10% / −20→−20% / −50→−30% / −100→−50% |
| 斬体耐性（%）・属性耐性（%） | `floor( 入力値 × 敵テンション補正 / 100 )`。倍率 = `(100 − 耐性%) / 100` |
| 属性耐性強制ダウン（%） | 敵テンションの影響を受けず、属性耐性%にそのまま加算（ロトの伝説・変異イオフォースなどは −50） |
| 因果の極み | 魔剣士専用。あり：因果合計にさらに +30% |
| 因果（段数） | 魔剣士専用。0〜6段、1段につき +20% |
| フォースブレイク（段数） | 0〜2段、1段につき +30% |
| 属性耐性変化（段数） | −3〜+3段。1段階で属性耐性 −20% |
| 閃き | なし ×1.0 ／ 1段階 ×1.4 ／ 2段階 ×1.8（会心種別が「通常」のときは強制 ×1.0） |
| きあいため | なし ×1.0 ／ きあいため ×2.0 ／ 超きあいため ×2.25 ／ 勇者の気合ため ×2.3（**第2段階**で乗算） |

**因果合計** = `1 + (段数×20 + 極み×30) / 100`  
**フォースブレイク＋属性耐性変化** = `1 + (FB段数×30 − 属性耐性変化段数×20) / 100`

### 斬体耐性変化

| 項目 | 説明 |
|------|------|
| 斬体耐性変化（棺など） | −3 → +105% / −2 → +70% / −1 → +35% / +1 → −20% / +2 → −40% / +3 → −60% |
| 衰弱（ラーミアなど） | 1〜3段階：+10 / +15 / +20% |
| 凍結（グリ爪など） | 1〜2段階：+10 / +15% |
| 戦意喪失 | 1〜3段階：+5 / +10 / +25% |

**斬体耐性変化合計** = `(100 + 斬体耐性変化 + 衰弱 + 凍結 + 戦意喪失) / 100`

### 会心ダメージ

| 項目 | 説明 |
|------|------|
| 会心ダメアップ（%） | `floor(入力値 × T)`。会心種別%に**加算**（乗算ではない）。種別が「通常」のときは無効 |
| 痛恨の一撃 | 魔人専用。+0 / +50 / +65 / +75 / +80 / +90 / +100%。会心合計に加算。「通常」のときは無効 |
| 会心ダメージ種別 | 通常 100% ／ 会心 160% ／ 多段・全体 180%（160〜200%）／ 超会心 250%（230〜270%） |
| ゾーン | ゾーン編成から自動反映 |

**会心合計** = `(会心種別% + 会心ダメアップ% + ゾーン + 痛恨) / 100`  
> 例：超会心250% ＋ 会心ダメアップ13% → `(250 + 13) / 100` = **2.63倍**（乗算ではなく加算）  
> 会心種別が「通常」の場合、会心ダメアップ・閃きはともに強制 ×1.0 で無視されます。

### 二刀流（第3段階）

魔人専用。**二刀流補正（%）** を `÷100` して第3段階で乗算し、**切り上げ**ます（100 = 補正なし）。

---

## 計算式（全体フロー）

```
① LvUP倍率   = floor( 1.04^段数 × 100 ) / 100
   LvUP加算値 = floor( 攻撃力 × LvUP倍率 ) − 攻撃力
   剣魔合一   = floor( 入力値 × LvUP倍率 )

② 敵LvDown係数 = ceil( 0.96^段数 × 100 ) / 100
   守備力変化  = floor( 守備力 × 段数 × 20% )
   最終守備力  = floor( 守備力 × LvDown係数 ) + 守備力変化　（直撃時は 0）

③ 基礎値     = floor( (攻撃力 + バイシオン + LvUP + 剣魔合一) / 2 − 最終守備力 / 4 )

④ 乱数幅     = floor( 基礎値 / 16 )
   下限基礎値 = floor( 基礎値 − 乱数幅 ) − 1
   上限基礎値 = floor( 基礎値 + 乱数幅 ) + 1

⑤ ゾーン編成から T と ゾーン値（斬体/属性/会心）を決定
   自分がゾーン → T = 1.5 固定 ／ それ以外 → T = 1 + 味方テンション補正%

⑥ テンション補正
   斬体% / 属性% / 系統% / 名称% / 会心ダメアップ% → floor( 入力値 × T )
   斬体耐性% / 属性耐性% → floor( 入力値 × 敵T補正 / 100 )
   （属性耐性%には強制ダウンを加算）

⑦ 各倍率（%→倍率変換後は小数第3位切り捨て）
   斬体合計         = floor( (100 + 斬体% + その他 + スキルUP + 斬体UP + おうえん + ゾーン + ゴッドレイジ + 会心必中) / 100 × 1000 ) / 1000
   属性合計         = floor( (100 + 属性% + FC×30 + FB + ゾーン) / 100 × 1000 ) / 1000
   系統合計         = floor( (系統% + 100) / 100 × 1000 ) / 1000
   名称合計         = floor( (名称% + 100) / 100 × 1000 ) / 1000
   因果合計         = 1 + (段数×20 + 極みあり×30) / 100
   FB＋属性耐性変化 = 1 + (FB段数×30 − 属性耐性変化段数×20) / 100
   会心合計         = (会心種別% + 会心ダメアップ% + ゾーン + 痛恨) / 100　（通常は強制 1.0）
   斬体耐性変化合計 = (100 + 斬体耐性変化 + 衰弱 + 凍結 + 戦意喪失) / 100

⑧【第1段階】= floor( 基礎値 × スキル倍率 × 斬体合計 × 属性合計
                    × 系統合計 × 名称合計 × 因果合計 × (FB＋属性耐性変化)
                    × 斬体耐性 × 属性耐性 × 閃き × 会心合計 × 斬体耐性変化合計 )

⑨【第2段階】= floor( ⑧ × (1 + スキル倍率補正 / 100) × きあいため )

⑩【第3段階】最終ダメージ = ceil( ⑨ × 二刀流補正 / 100 )

※ 最小は下限基礎値・会心下限%、最大は上限基礎値・会心上限%で ⑧〜⑩ を同様に計算
```

# 🔮 呪文ダメージ計算機

物理ダメージ計算機をベースにした、呪文用の計算機です。

## 武器

武器を選ぶと、基礎値が決まります。

| 武器 | 最小ステ | 最小威力 | 最大ステ | 最大威力 |
|------|---------|---------|---------|---------|
| ラブ・ストリーム(1体) | 15 | 633 | 1950 | 12945 |
| メラガイアー | 10 | 600 | 2400 | 11000 |

- 最終攻撃魔力が **最小ステ〜最大ステの間** にあるとき、威力は線形補間で求めます
- 最小ステ以下は最小威力、**最大ステ以上は最大威力で頭打ち（キャップ）** です
- **基礎値** = `floor( 武器威力 )`（乱数幅は物理と同じ `±floor(基礎値/16) ± 1`）

## 入力項目

| カード | 項目 |
|--------|------|
| 攻撃魔力・基礎値 | 攻撃魔力、レベルアップ（段数・物理と同じ式で攻撃魔力が上がる） |
| 呪文ダメージ倍率 | 呪文ダメージ倍率（%）。**他の加算グループとは乗算**（独立） |
| テンション・ゾーン編成 | 物理と同じ。ゾーンの種類は「スキル」（旧：斬体）・属性・「暴走」（旧：会心） |
| 呪文ダメージ | スキルダメージアップ（最大2段階）／呪文ダメージアップ（魔力覚醒など・1段階 +20%、最大3段階）／おうえん／魔響の詠唱（あり +20%）／ゾーン |
| 属性ダメージ | 属性倍率／フォースチャージ／フォースバースト（あり +50%）／ゾーン |
| 系統・名称ダメージ | 系統倍率／名称倍率 |
| 敵テンション・耐性補正 | 呪文耐性／属性耐性／属性耐性強制ダウン／因果の極み／因果／フォースブレイク／属性耐性変化 |
| 呪文耐性変化 | 衰弱／凍結／戦意喪失／呪文耐性減（ディバインスペルなど・1段階 +20%、最大3段階） |
| 暴走ダメージ | 暴走ダメアップ（%）／ゾーン／暴走（種別）／暴走ダメージ（ケキなど） |

**呪文ダメージ倍率合計** = `floor( (floor(入力値 × T) + 100) / 100 × 1000 ) / 1000`  
**呪文合計** = `floor( (100 + スキルUP + 呪文ダメージアップ + おうえん + 魔響の詠唱 + ゾーン) / 100 × 1000 ) / 1000`  
**属性合計** = `floor( (100 + 属性% + FC×30 + フォースバースト + ゾーン) / 100 × 1000 ) / 1000`  
**呪文耐性変化合計** = `(100 + 衰弱 + 凍結 + 戦意喪失 + 呪文耐性減) / 100`

### 暴走

| 種別 | 倍率 | 乱数 |
|------|------|------|
| なし | 100% | なし（固定） |
| 暴走 | 175% | 150〜200% |
| 超暴走lv1 | 300% | なし（固定） |
| 超暴走lv2 | 410% | なし（固定） |
| 超暴走lv3 | 530% | なし（固定） |
| 超暴走lv4 | 650% | なし（固定） |
| 超暴走max | 770% | なし（固定） |

- 乱数があるのは **通常の暴走（150〜200%）のみ**。超暴走は固定値です
- **暴走合計** = `(暴走種別% + 暴走ダメアップ% + ゾーン) / 100`
- 暴走が「なし」のときは、暴走ダメアップ・ゾーンの暴走・暴走ダメージ（ケキなど）はすべて無効（×1.0）です
- 暴走ダメージ（ケキなど）：なし ×1.0 ／ 1段階 ×1.4 ／ 2段階 ×1.8

## 計算式

```
① 最終攻撃魔力 = floor( 攻撃魔力 × floor(1.04^段数 × 100) / 100 )

② 武器威力 = 最小威力 + (最大威力 − 最小威力) × (最終攻撃魔力 − 最小ステ) / (最大ステ − 最小ステ)
   （最大ステ以上は最大威力）
   基礎値     = floor( 武器威力 )
   下限基礎値 = floor( 基礎値 − 乱数幅 ) − 1 ／ 上限基礎値 = floor( 基礎値 + 乱数幅 ) + 1

③ T = 自分がゾーン ? 1.5 : 1 + 味方テンション補正%
   呪文ダメージ倍率% / 属性% / 系統% / 名称% / 暴走ダメアップ% → floor( 入力値 × T )

④ ダメージ = floor( 基礎値 × 呪文ダメージ倍率合計 × 呪文合計 × 属性合計 × 系統合計 × 名称合計
                    × 因果合計 × (FB＋属性耐性変化) × 呪文耐性 × 属性耐性
                    × 暴走ダメージ(ケキなど) × 暴走合計 × 呪文耐性変化合計 )

※ 最小は下限基礎値・暴走の下限、最大は上限基礎値・暴走の上限で同様に計算
```

## 山彦ダメージ

結果欄の **中央値の下** に表示されます。`floor( 中央値ダメージ × 80% )` です。

## 保存

物理ダメージ計算機と同様に、入力値の自動保存と履歴スロット（3件）があります。保存領域は物理・回復とは別です。

# 💚 回復量計算機

## 武器

武器には **とくぎ** / **呪文** の属性があります。装着する心の属性と一致しない場合、その心の「呪文とくぎHP回復効果%」は無効になります。

| 武器名 | 属性 | 基礎回復量の式（回復魔力 = x） | 回復魔力上限 |
|--------|------|------------------------------|-------------|
| 道示す光 | とくぎ | 89 + 0.09 × x　（1600→233、1900→260の2点から算出） | 1900 |
| 女神の奇跡 | 呪文 | 103.6 + 0.084 × x　（1600→238、2100→280の2点から算出） | 2100 |
| いやしの占術 | とくぎ | 82 + 0.08667 × x　（900→160、1350→199の2点から算出） | 1350 |

武器ごとの基礎回復量は、実測値の2点から求めた直線で計算します。

## 入力項目

### ステータス

各ステータスは **未装着**（心なし）と **装着後**（心込み）のどちらからでも入力できます。片方を入力すると、自動でもう片方に反映されます。

| 項目 | 説明 |
|------|------|
| 回復魔力 | 武器の基礎回復量に影響。武器ごとの上限あり |
| スキルHP回復効果（%） | 基礎回復量への乗算倍率 |
| とくぎ/呪文HP回復効果（%） | 基礎回復量への乗算倍率。武器と心の属性が不一致の場合、心による加算分は無効 |

### レベルアップ・テンション

| 項目 | 説明 |
|------|------|
| レベルアップ（段数） | 回復魔力に `floor(1.04^段数 × 100) / 100` を乗算（武器の上限でカット） |
| テンション | 0 / 5 / 20 / 50 / 100。スキルHP回復%・とくぎ/呪文HP回復% に T 倍率を乗算後、切り捨て |

## 計算式

```
① 実効回復魔力 = min( floor( (回復魔力 + 心の回復魔力合計) × レベル倍率 ), 武器上限 )

② 基礎回復量  = 武器固有の切片 + 傾き × 実効回復魔力

③ T = 1 + テンション補正%
   有効スキル%  = floor( スキルHP回復% × T )
   有効とくぎ%  = floor( とくぎ/呪文HP回復% × T )

④ 回復量 = floor( 基礎回復量 × (1 + 有効スキル% / 100) × (1 + 有効とくぎ% / 100) )
```

## こころ（自由欄）

4つのスロットに心を装着できます。各スロットは独立して選べ、ステータスはすべて加算されます。  
初期状態は 風の精霊／リュウちゃん(緑)／破壊の邪神シドー／メイデンドール です。

選択肢には、名前の横に `回163ス10呪特2` のような短い表記で数値が出ます。

| 記号 | 意味 |
|------|------|
| 回 | 回復魔力（覚醒＋込み） |
| ス | スキル回復効果% |
| 呪 | 呪文回復効果%（呪文専用の心） |
| 特 | とくぎ回復効果%（とくぎ専用の心） |
| 呪特 | 呪文・とくぎ兼用 |

値が0の項目は省略します。

### 装着ルール（オート選択のみ）

手動で選ぶときは制限がなく、同じ心を複数のスロットに入れることもできます。⚡ オートが自動で選ぶときだけ、次のルールが適用されます。

- 同じ心の(緑)と(緑+他)は **同時に選ばれません**（同じ心の扱い）
- (緑)の心は **1つまで** しか選ばれません（もう一方は(緑+他)）

### 覚醒＋

心ごとの入力欄（0〜25。いびつ世界の幻竜のみ 0〜50）に値を入れると、その心を装着したときだけ **回復魔力に加算** されます。

- どのスロットに装着していても共通の値です（スロットごとの個別設定ではありません）
- 同じ心の(緑)と(緑+他)は、同じ値を共有します
- 選択肢の表示（回復魔力に含めて表示）と、オート選択にも反映されます
- 対象：リュウちゃん／いびつ世界の幻竜／破壊の邪神シドー／魔王バラモス／ナウマンボーグ
- 初期値は、いびつ世界の幻竜のみ 25、それ以外は 0 です

### コスト管理

装着中の心のコスト合計が、**最大コスト** を超えないようにします。

**最大コスト** = レベル基礎値 + 装着中の心の「上限ボーナス」の合計

|----|----|----|----|----|----|----|----|----|----|----|----|----|----|----|----|----|
| 基礎値 | 730 | 724 | 718 | 712 | 706 | 700 | 694 | 689 | 683 | 678 | 673 | 667 | 661 | 655 | 649 | 643 |

合計コストが上限を超えると、赤字で警告が表示されます。

### ⚡ オートボタン

現在の武器・キャラレベル・コスト上限・各ステータスを考慮して、**回復量が最大になる心の組み合わせ** を自動で選びます（全組み合わせを探索します）。
